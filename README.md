Magnetic is a web based application that provides NUS Students the opportunity to make friends through shared interests and common activities. 

## Key features
- Signup and Login Authentication System
- Profile Creation and Management
- Friends List and Management
- Activity Creation and Management
- Activity Browser and Filtered Search
- Recommend an Activity
- Recommend a User
- Activity Creation Suggestion

## Tech Stack
- HTML, CSS, Javascript, SQL
- Supabase
- Gemini Flash 2.5
